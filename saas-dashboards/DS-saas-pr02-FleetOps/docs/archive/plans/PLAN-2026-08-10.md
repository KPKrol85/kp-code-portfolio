- [x] **PH7-02 — Correct service-worker navigation response handling** — **Priority:** High
  - [x] stop treating a fulfilled HTTP response as a network failure — `networkFirstNavigation` in `public/sw.js` threw `new Error("Network error")` whenever `!response.ok`, so the host's own answer was discarded for every non-2xx navigation. With PH7-01 leaving unmatched paths to the platform's custom-404 handling, a service-worker-controlled client requesting an unknown URL online received a valid HTTP 404, had it converted into a synthetic failure, missed in the navigation cache and was served `Response.error()` — a browser network-error page instead of the error document. The synthetic throw was removed: a fulfilled `fetch(request)` now returns its response to the browser unchanged, whatever the status
