### Added

- Added the initial Axiom construction website implementation: home page, six service subpages, five legal subpages, a form success page, an offline page, and a custom 404 page.

- Added guarded `localStorage` access in `js/utils/storage.js` so theme and cookie-consent state degrade silently when browser storage is unavailable.
- Added a centralized SVG icon system and refactored the footer social row onto it: the new `js/components/icons.js` holds the GitHub, Facebook, Instagram, and X path data once behind the stable ids `icon-github`, `icon-facebook`, `icon-instagram`, and `icon-x`, and its `initIcons()` builds a single hidden `<symbol>` sprite through `document.createElementNS` — no `innerHTML`, no inline style, no new dependency — inserting it once per document under the guard of its own host id and running first in `initApp()`, so no page needs a second script tag;
